# JARVIS Mark LV — Alle Funktionen

**Ein KI-Assistent von FatihMakes**
Version: Mark LV | Sprache: Deutsch/Englisch | Plattform: Windows (macOS/Linux kompatibel)

---

## Schnellstart

1. `install.bat` doppelklicken (installiert alles)
2. Gemini API-Key eingeben (kostenlos: https://aistudio.google.com/apikey)
3. `start.bat` doppelklicken

---

## Alle Funktionen im Detail

### Sprachassistent (Gemini Live)
- Echtzeit-Gespräch mit JARVIS ueber Mikrofon
- Natuerliche Sprache (Deutsch/Englisch/weitere)
- Wake Word: "Hey Jarvis" (optional aktivierbar)
- Push-to-Talk Modus
- Hologramm-Avatar mit Lippensynchronisation
- Session-Gedaechtnis (erinnert sich an fruehere Gespraeche)
- Automatischer Modell-Wechsel bei Quota-Limit

## Konfiguration

Alle Einstellungen in `config/api_keys.json`:

| Einstellung | Beschreibung | Pflicht |
|------------|-------------|--------|
| gemini_api_key | Google Gemini API Key | Ja |
| user_name | Dein Name | Nein |
| dashboard_pin | Login-PIN (Standard: JARVIS) | Nein |
| discord_bot_token | Discord Bot Token | Nein |
| discord_channel_id | Discord Standard-Channel | Nein |
| ngrok_url | ngrok URL fuer Remote-Zugang | Nein |
| camera_index | Kamera-Nummer (Standard: 0) | Nein |
| morning_brief_enabled | News beim Start (true/false) | Nein |
